# 짤카드 스튜디오

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 파일로 내려받는, 로그인이 필요 없는 정적 웹 편집기입니다.

- 데모: https://claude.ai/artifact/Y8LXFKLL5rdw1zjQZ66xKP
- 실행: `index.html`을 브라우저로 열면 바로 동작합니다 (서버/빌드 불필요).

## 기능

- PNG/JPEG 이미지 업로드 — 매직 바이트 검증, `createImageBitmap` 실제 디코드 검증으로 손상 파일 거부, 캔버스 재인코딩으로 EXIF/위치 메타데이터 자동 제거
- 문구 편집 — 내용/위치(드래그 또는 슬라이더)/크기/색/정렬/외곽선/배경 박스, 자동 줄바꿈 및 과도한 길이일 때 자동 축소(autofit)
- 1:1 · 4:5 · 9:16 화면비, 미리보기 캔버스가 곧 다운로드 파일이라 항상 일치
- PNG/JPEG 다운로드 — `downloads` 런타임 capability 우선 사용, 미지원 환경에서는 이미지를 화면에 띄워 수동 저장(우클릭)하도록 대체
- 템플릿 생성/불러오기/이름수정/현재 내용 갱신/삭제 (localStorage, 새로고침 후에도 유지)
- 템플릿 JSON 내보내기/가져오기 — 문법 오류·필수 항목 누락 시 기존 템플릿을 건드리지 않고 거부

## 안전/개인정보

- 서버 없이 전부 브라우저 안에서 처리되어 이미지·문구가 외부로 전송되지 않습니다.
- 업로드된 이미지는 항상 캔버스로 재인코딩되어 EXIF(위치정보 포함) 메타데이터가 남지 않습니다.
- 로그인/계정/쿠키 동의 등이 없어 개인정보를 수집하지 않습니다.
